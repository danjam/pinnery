# Security

## Reporting a vulnerability

Please don't open a public issue. Report it privately instead, using [this form](https://github.com/danjam/pinnery/security/advisories/new) (or **Security** → **Report a vulnerability**). Only the maintainer can see the report.

Include what you found, how to reproduce it, and which version you're running (shown at `/healthz`).

## Supported versions

Only the latest release gets security fixes. Update to it before reporting if you can.

## What to expect

- An acknowledgement within a few days.
- A fix in the next release, with the report published once it's out.
- Credit in the advisory, if you'd like it.
